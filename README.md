# Pickomino（骰子虫子牌）

Heckmeck 风格的骰子游戏：掷 8 颗骰子，留骰凑点数，抢烤架上的虫子牌。

## 玩法

- 每回合掷 8 颗骰子（1–5 和虫面，虫面按 5 点算）。
- 每次掷完必须**留下至少一颗**：选一个掷出来的面，把该面**全部**骰子收走；同一个面一回合只能留一次。
- 留完可以停手或继续掷剩下的骰子；如果掷出的面都已经留过，**爆掉**。
- 停手时点数 = 留下的骰子点数之和，且**必须至少留过一颗虫**才能拿牌。
- 拿牌：点数对应的牌（21–36）在烤架上就直接拿走；若对手最上面一张正好是该点数，可以**偷走**；否则拿烤架上不大于点数的最大牌。
- 爆掉：失去自己最上面一张牌（移出游戏）；没牌则无事发生。
- 烤架清空时游戏结束，虫子总数多者获胜。

## 用法

```bash
python3 -m pickomino auto --games 10 --seed 42   # AI 自动对局
python3 -m pickomino auto --games 1 --seed 7 --verbose  # 看逐掷过程
python3 -m pickomino play                        # 人机对战（你是玩家0）
```

人机对战输入：`1`–`5` 留对应点数，`虫`/`w` 留虫面，`s` 停手，`q` 退出。

## AI 说明

贪心启发式：优先留虫（拿牌必需），否则留期望点数最高的面；停手决策用爆掉概率近似
`（已留面数/6)^剩余骰数`，点数越高阈值越保守。无多步搜索。

## 已知局限（诚实版）

- AI 只是单步贪心，不懂长线规划与针对性偷牌；熟悉规则的人类通常能赢。
- 规则为简化版：爆掉失去的牌直接移出游戏（与原版翻面规则等价效果）；只支持 2 人。
- 纯文本界面，无图形/动画/存档/悔棋/网络对战；Python 3.10+，纯标准库。
